# حسرت دوکان — د Android پروژې سرچینه

دا د Android Native/Kotlin پروژې لومړنۍ فعاله نسخه ده؛ ویب‌پاڼه نه ده. معلومات په محلي SQLite ډیټابېس کې ساتي او د عادي کار لپاره انټرنېټ ته اړتیا نه لري.

## شاملې ځانګړنې
- د لومړي ځل پرانیستلو پر مهال د مدیر پاسورډ جوړول
- پښتو RTL انٹرفېس او AFN
- د محصولاتو لومړنی نوملړ او اته ګدامونه
- د مال ثبت، کوډ/بارکوډ، تعداد، اصلي او خرڅلاو قیمت
- د پېرود، خرڅلاو او بېرته اخیستلو ثبت او د موجودۍ بدلون
- د مشتریانو پور ثبت او پاتې پور ښودل
- ورځني لګښتونه
- د ګدامونو او عمومي موجودۍ راپور
- د ZXing له لارې د کامرې بارکوډ سکین

## د APK جوړولو اړتیا
په دې چاپېریال کې Android SDK او Gradle نه شته؛ له همدې امله دلته APK نه دی compile شوی. د APK جوړولو لپاره:
1. په کمپیوټر کې Android Studio نصب کړه.
2. دا پروژه په Android Studio کې Open کړه.
3. د Gradle Sync بشپړېدو ته انتظار وباسه.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) وټاکه.
5. APK به د `app/build/outputs/apk/debug/app-debug.apk` په مسیر کې جوړ شي.
6. APK موبایل ته ولېږه، فایل خلاص کړه او که اجازه وغواړي د همدې فایل منېجر لپاره Install unknown apps فعال کړه.

## مهمه یادونه
دا نسخه د کار وړ بنسټ/Prototype دی، خو لا د تولیدي بشپړ حسابدارۍ سیستم ټولې غوښتنې نه پوره کوي: د بیک‌اپ صادرول/واردول، د پور تادیاتو تاریخ، د ګدام ترمنځ انتقال، د ورځې بندول، د خرڅلاو/پېرود بشپړ رسیدونه، د تاریخ له مخې راپورونه، د هر جنس دقیق ګټه/تاوان او د معلوماتو د اصلاح بشپړ UI باید په راتلونکې نسخه کې ورزیات شي. د مهمو سوداګریزو معلوماتو لپاره تر ازموینې مخکې یوازې پر دې نسخه تکیه مه کوه.
